# IBM-Data-Science-Capstone
IBM Data Science Capstone Project
SpaceX Falcon 9 First Stage Landing Prediction
### Project Overview

This project was completed as part of the IBM Data Science Professional Certificate Capstone.

The objective is to predict whether the Falcon 9 first stage will successfully land. Successful landings allow SpaceX to reuse rocket boosters, significantly reducing launch costs.

### Business Problem

SpaceX advertises Falcon 9 launches at approximately $62 million compared to competitors that may charge over $165 million. Predicting landing success helps estimate launch costs and supports decision-making for competing aerospace organizations.

### Project Workflow

1. Data Collection
  Collected launch data using the SpaceX REST API
  Scraped historical launch records from Wikipedia

2. Data Wrangling
  Cleaned and transformed collected datasets
  Handled missing values
  Created features for analysis

3. Exploratory Data Analysis
  Visualization using Python
  SQL analysis using SQLite

4. Interactive Visual Analytics
  Interactive launch site maps using Folium
  Dashboard development using Plotly Dash

5. Predictive Analysis

### Evaluated several machine learning models:

  -Logistic Regression

  -Support Vector Machine (SVM)
  
  -Decision Tree
  
  -K-Nearest Neighbors (KNN)
